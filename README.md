# Дизайн-концепция v2 «Точность потока» — ГК «УЛЬТРА»

Версия 2 — по разбору референсов (`../Референсы.md`). Первая версия сохранена в `../concept-v1`.

## Что сделано по 10 пунктам
1. **Lenis + GSAP ScrollTrigger** — плавная инерционная прокрутка, анимации привязаны к прокрутке.
2. **Закреплённая сцена «внутрь прибора»**: OPTISWIRL 4200 → камера влетает во фланец → туннель трубы с параболическим профилем скорости → дорожка Кармана за телом обтекания + осциллограмма датчика → выход обратно к прибору. 4 главы, точки-прогресс, счётчик 01/04.
3. **Прелоадер-HUD**: кольца-шкала, орбиты, `[ РАСХОД ] [ УРОВЕНЬ ] [ ПОВЕРКА ]`, счётчик 000 → 100, кольца уходят в 3D. Один раз за сессию.
4. **Типографика**: Inter Tight 300 крупным кеглем + JetBrains Mono для подписей. Заголовки проявляются из размытия по буквам.
5. **Палитра**: почти чёрный фон, фиолетовый бренда — только поверхности и «занавес», бирюза — единственный акцент (действия и живые данные).
6. **Одометры** 25 / 5 лет / 0,1 % / 4 офиса — цифры прокручиваются барабаном.
7. **Манифест** закрашивается по словам при прокрутке.
8. **Каркасная схема узла учёта** рисуется линиями, по трубе бежит поток.
9. **Острые углы, линии-разделители, моно-метки** с квадратиком-маркером, шапка из тёмных плашек, круглый вращающийся бейдж «Отправить запрос».
10. **Шторка-переход** между страницами в цвет бренда.

Дополнительно: hero в редакционной вёрстке (фото на весь экран, огромный заголовок, CTA-блок справа), «занавес» с отраслевыми решениями лесенкой, фото направления едет за курсором, шкала-прогресс услуг.

Запуск: `python3 -m http.server 8746` в этой папке → http://localhost:8746

## Экраны
- `index.html` — главная
- `catalog.html?s=flow|level|aux` — раздел каталога с умным фильтром
- `product.html?id=optiswirl4200` — карточка прибора (работает для любого id из `data.js`)

## «Вау»-моменты v1 (исторические)
1. **Hero — живой поток в трубе.** Параболический профиль скорости, как в настоящей трубе. Курсор работает как тело обтекания: за ним срываются вихри — это принцип вихревого расходомера OPTISWIRL. Рядом «живая телеметрия» Q / P / T.
2. **Прибор-экспонат** с выносками характеристик, вращающимися кольцами и свечением.
3. **«Подбор за 10 секунд»** на главной: задача → среда → исполнение, счётчик подходящих приборов, переход в каталог с уже выставленным фильтром.
4. Заголовки выезжают по словам, секции появляются при прокрутке, счётчики анимируются, параллакс фото, карточки подсвечиваются за курсором, таймлайн услуг заполняется при прокрутке.

## Как концепция закрывает желания клиента
| Желание (ТЗ) | Где в концепции |
|---|---|
| Новый дизайн, структура старая (3.2, 3.3) | Те же разделы: каталог из 3 направлений, решения, услуги, опросные листы, справочник, компания, контакты |
| Плитки с 3–5 характеристиками (6.1) | Плитка: тип, название, 3–4 ключевых свойства, «Запросить ТКП» |
| Умный фильтр до 4 параметров (6.3) | Среда / сигнал / исполнение Ex / отрасль; пустые значения скрываются; счётчики; фильтр в адресе страницы |
| Фильтр «применение в промышленности» (6.3.4, 6.4) | Один справочник отраслей: фасет фильтра + отраслевые карточки + блок «Применение» в карточке |
| Документы с типизацией (4.4) | Сертификат / СИ / МП / РЭ / ОЛ с размером и сроком действия |
| Формы, автоподстановка товара, без CAPTCHA (6.5, 7.4) | Модалка «Запрос ТКП» / «Заказать звонок», honeypot, прикрепление опросного листа |
| Поиск (6.9) | Иконка в шапке и клавиша «/» — поиск по приборам, разделам, услугам |
| Адаптив (3.5) | Десктоп / планшет / мобильный; фильтр на мобильном — нижняя шторка |
| Скорость PageSpeed (7.5) | Без видео и WebGL; анимация холста ставится на паузу вне экрана; учтён `prefers-reduced-motion` |

## Условности
- Значения характеристик, кроме OPTISWIRL 4200, условные — матрица свойств составляется на этапе аналитики.
- 3 отраслевых решения — подтверждённые; расширенный набор отраслей показан только как значения фильтра (вопрос 13.12 открыт).
- Новости и номер заявки — заглушки.
